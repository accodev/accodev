### Work

- **fiskaltrust** (2025 to now), Senior Software Engineer. Core framework of the Italian virtual tax registration system (TRS), which replaces the RT fiscal printers before the late-2026 mandate. An internal LangChain RAG assistant over fiscal and technical docs for customer support. Azure Kubernetes workloads that route receipts to national tax authorities.
- **Invenco by GVR** (2024 to 2025), Software Developer, Client Solutions. Custom C# backends and frontends that fit the core product to each client.
- **En.Te.R. Team** (2009 to 2024), Software Developer. C++14/17 device drivers, C# .NET e-invoicing to Agenzia delle Entrate, payment middleware on IFSF, OPOS, ISO 8583 and EMV, a Vue.js back office, and the move of the code base to Git and GitHub.

### Homelab

- **ZeroClaw agent**: a persistent [ZeroClaw](https://github.com/zeroclaw-labs/zeroclaw) 0.8.7 agent on a home server, reachable from Telegram. It runs a local model on a GTX 1080 Ti and falls back to OpenRouter under a monthly budget cap, asking first.
- **Admin tools over MCP**: a custom MCP server gives the agent host status and media tools. Service restarts and media changes need approval. The agent runs sandboxed as its own user under systemd.
- **Storage and network**: RAID 5 NAS with rsync backups on the 3-2-1 rule, a Pi-hole DNS sinkhole and WireGuard VPN, on Proxmox and Docker since 2017.
